# Hardware

## What you need

- **Sipeed Tang Nano 20K.**
- **HDMI display or capture card:** 720×480p input.
- **Optional:** a 1.44" 128×128 ST7735S SPI LCD module (the common red board with SCL/SDA/RES/DC/CS/BL pins).
- **Optional:** a DualShock 2 and the Sipeed DualShock adapter, and/or 8 push buttons.

## Pin map

All signals are on the two header rows of the Tang Nano 20K. The constraints are in `rtl/board/tangnano20k.cst`.

### Buttons

Each button connects its pin to **GND**; the FPGA's internal pull-ups are enabled, so no resistors are needed. The inputs are synchronized and debounced (2 ms sampling, two equal samples).

| Button | Pin | | Button | Pin |
|---|---|---|---|---|
| Up | 25 | | A | 29 |
| Down | 26 | | B | 30 |
| Left | 27 | | Select | 31 |
| Right | 28 | | Start | 77 |

Select + Start together opens the menu, as on the DualShock.

### ST7735S LCD

| LCD pin | FPGA pin | Notes |
|---|---|---|
| VCC | 3V3 | |
| GND | GND | |
| SCL / SCK | 73 | 16.875 MHz (clk_sys / 2) |
| SDA / MOSI | 74 | |
| RES / RST | 71 | reset is generated by the FPGA after power-up |
| DC / A0 | 72 | |
| CS | 53 | |
| BL / LED | 52 | driven high (backlight on) |

**If the picture is shifted, mirrored or has swapped colors:** 1.44" modules differ, and the driver has parameters for that in `rtl/top/gbc_top.sv`:

```verilog
lcd_st7735 #(.CLK_HZ(33_750_000)) u_lcd (...);
//  parameters (defaults):
//    SPI_HALF = 1       SCL half period in clk cycles; 2 = 8.4 MHz if long wires cause errors
//    MADCTL   = 8'hC8   MY|MX|BGR. Bit 3 (BGR) swaps red/blue; MX/MY (bits 6/7) mirror, MV (bit 5) rotates
//    X_OFS    = 2       column offset of the 128x128 window in the 132x162 panel RAM
//    Y_OFS    = 3       row offset (some modules need 1 or 32)
//    INVERT   = 0       1 sends INVON (some IPS variants show inverted colors otherwise)
```

**How the LCD output works:**
- The pixel stream is the same one that feeds the HDMI framebuffer. It is converted to RGB with the same palette and color-correction settings, then scaled.
- The image is stored in a 128×128 × 13-bit BSRAM frame (R4 G5 B4). It is sent to the panel continuously: 16384 pixels × 16 bit at 16.9 MHz, about 64 fps. The panel has no tearing-effect pin wired, so fast scrolling can show a tear line.
- *Fit*: 2-tap filter in both directions (5 → 4 pixels): 160×144 becomes 128×115, centered with black bars.
- *Crop*: the center 128×128 (columns 16–143, rows 8–135) at 1:1.

### DualShock 2

Use the Sipeed adapter on pins 17–20, the same as NESTang. These pins are shared with LEDs 2–5. The controller is polled continuously by `rtl/io/dualshock_controller.v`.

| PS2 | Game Boy |
|---|---|
| D-pad | D-pad |
| ○ / △ | A |
| ✕ / □ | B |
| Start / Select | Start / Select |

### Board buttons and LEDs

| | Function |
|---|---|
| S1 (pin 88) | open / close the menu |
| S2 (pin 87) | reset the game |
| LED0 | lit while a game is loading |
| LED1 | lit while the menu is open |

### USB-UART

The BL616 debugger exposes a serial port (COM*n* on Windows) wired to FPGA pin 70. The design receives 115200 8N1 commands on it. See [remote.md](remote.md).
