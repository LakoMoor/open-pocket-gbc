START / CONNECT

Без установки.

Всё общение с платой происходит на твоём компьютере.

01

Открой в Chrome или Edge

Нужен браузер на компьютере с Web Serial и страница по HTTPS или localhost. Firefox, Safari и мобильные браузеры здесь не поддерживаются.

02

Подключи USB

Закрой Studio, терминал и другие программы, занявшие COM-порт. Нажми «Подключить плату» и выбери USB Serial Port платы: UART / интерфейс B.

03

Играй и настраивай

Кнопки работают сразу. Экран требует прошивку и битстрим 1.3+, настройки — прошивку 1.6+. Новая прошивка 1.9 также сообщает свою версию при подключении.

Обновление прошивки и битстрима

Веб-пульт не прошивает плату. Для обновления используй Studio или скопируй opgbc_fw.bin и opgbc_fpga.bin в корень microSD, затем открой System → System Update на плате. После обновления битстрима выключи и включи питание.
