Open Pocket.
Game Boy, reimagined
on a $25 FPGA.

The MiSTer Game Boy Color core on a Sipeed Tang Nano 20K, with HDMI, a 1.44" LCD, an Analogue-style menu and a link port to the original hardware. Every bit built with open-source tools.

Eight themes

Your menu.
Your look.

Analogue OS, Ozone, XMB, Pocket, Game Boy, iPod, BIOS setup and a terminal. Each one has its own layout on HDMI and on the small screen, down to radio buttons and marquee text.

HDMI, captured from the board. Analogue OS, Ozone, XMB, Pocket, Game Boy, iPod, BIOS, Terminal.

The same eight, on 128 × 128.

The 1.44" LCD gets layouts made for sixteen columns: an icon sidebar for Ozone, a category row for XMB, a cursor arrow for Game Boy, an inverse bar for the terminal. Text that doesn't fit scrolls.

Home screen

Something to look at.
Something to hear.

With no game loaded, a built-in ROM plays behind the menu: a synthwave sunset, deep space with a ringed planet, or a rainy night city with lightning. Each has its own chiptune on all four channels.

Per-scanline colour and scroll tables drive the gradients, the parallax and the moving floor grid, in GBC double speed and on a DMG too.

Features

Everything a handheld
needs. And then some.

MiSTer core

GB and GBC, double speed, HDMA, MBC1/2/3/5, HuC1/3. Games from the SD card, the internal flash or a W25Q "cartridge".

HDMI and LCD

480p HDMI with audio, triple-buffered. A 1.44" ST7735 LCD at 60 fps in Fit or Crop. Pixel grid and scanline modes, five DMG palettes.

Link cable

Play with an original Game Boy: SC, SI and SO on three header pins through a 3.3 / 5 V level shifter.

Fast forward

Double speed from the menu or while holding R. The core runs at 120 fps.

Game Genie

Codes per game with an editor, applied as ROM patches in SDRAM and reverted exactly when switched off.

Screenshots

BMP files on the SD card from the menu or with L, even with HDMI switched off.

Recent games

The last eight games with the time spent in each, one press from the main page.

System Update

New firmware or FPGA bitstream from the SD card, with progress and a verify step. No PC needed.

Battery mode

HDMI off, SDRAM power-down and self-refresh, 30 fps LCD, dimming and a sleep timer.

Build

Source to bitstream.
Open all the way.

yosys with slang, GHDL for the VHDL parts, nextpnr-himbaechel, Apicula and openFPGALoader. RISC-V GCC for the menu, RGBDS for the home screen ROM.

# the bitstream (~20 min) and the firmware
./build.sh gbc_top
bash fw/build.sh

# both into the board's flash
./flash.sh all

# games into the internal flash
python tools/make_games.py build/games.bin \
    games/ucity.gbc=uCity games/libbet.gb
./flash.sh games
# files for System Update on the SD card
python tools/make_update.py

# the desktop app
cd apps/studio && npm install && npm start

# play from the keyboard, or script it
python tools/remote.py "M . D D A"

# a picture of the menu, no capture card
python tools/lcd_shot.py lcd.png --osd hdmi.png
