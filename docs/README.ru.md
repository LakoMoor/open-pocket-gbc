# Open Pocket GBC

**Game Boy / Game Boy Color на Sipeed Tang Nano 20K: HDMI, меню в стиле Analogue Pocket, игры с SD-карты или встроенной flash, рабочие сохранения, SPI-дисплей и пищалка. Собирается только открытыми инструментами.**

[English version](../README.md)

![uCity на Tang Nano 20K с debug-строкой](img/ucity.gif)

На FPGA GW2AR-18 платы нативно работает ядро Game Boy из MiSTer. Картинка идёт по HDMI (480p, увеличение в 3 раза, со звуком) и одновременно на дешёвый 1.44" дисплей ST7735S. Меню работает на маленьком процессоре RISC-V внутри FPGA: он загружает игры с microSD-карты или встроенной SPI-flash, пишет сохранения и хранит настройки. Вся цепочка от исходников до прошивки открытая: yosys + slang, GHDL, nextpnr-himbaechel, Apicula, openFPGALoader. Gowin IDE не нужна.

## Возможности

- **Ядро:** Game Boy из MiSTer, режимы GB и GBC, двойная скорость, HDMA, звук. Мапперы MBC1/2/3/5, HuC1/HuC3, ROM без маппера.
- **HDMI:** 720×480p, 59.94 Гц, картинка GB 480×432, звук 48 кГц стерео. 720p включается опцией сборки.
- **Режимы экрана как у Pocket:** *Sharp*, *LCD grid*, *Scanlines*. Пять палитр DMG. Цветокоррекция GBC, отключаемая.
- **Меню в стиле Analogue Pocket:** полноэкранный список с иконками, белая скруглённая полоса выбора, описание пункта и подсказки по кнопкам поверх затемнённой игры. Разделы: Library, Save Game, Reset, Display, Audio, Controls, System, Info, Sleep. Уведомления «Saved» и «HDMI off» всплывают поверх игры. Подробно — в [menu.md](menu.md).
- **Библиотека:** игры с **microSD** (FAT32 или exFAT, папки, длинные имена, ROM до 6 МБ) и из **встроенной flash** (до 15 игр). Меню, игры из flash, настройки и сохранения работают и без карты.
- **Сохранения переживают выключение:** автосохранение через 2 с после записи игры в RAM картриджа и при открытии меню. Для игр с SD — файл `<имя>.sav` рядом с ROM, для игр из flash — слот во flash, перезаписываются только изменившиеся сектора по 4 КБ.
- **Настройки запоминаются** во flash: режим экрана, палитры, громкость, модель, игра при включении, энергосбережение.
- **Энергосбережение:** HDMI выключается вместе со своим PLL долгим нажатием S1 или в меню, так что можно работать от одного LCD. Ещё: выключение и яркость подсветки LCD, режим сна и таймер сна (игра на паузе, HDMI и LCD выключены, любая кнопка будит), светодиоды по умолчанию выключены, flash уходит в глубокий сон, процессор меню во время игры стоит в аппаратном ожидании.
- **Пищалка / динамик:** звук сигма-дельтой на пинах 76 / 75 (пьезо между двумя пинами или динамик через усилитель), без постоянной составляющей и с усилением до x8.
- **Режим Battery:** один переключатель (System → Power Mode или держать S2) полностью выключает HDMI (PLL, выходы в третьем состоянии, фреймбуфер не пишется), приглушает LCD и гасит подсветку через 30 с без нажатий, выключает светодиоды, засыпает через 5 минут.
- **Картридж:** внешняя флешка W25Qxx на четырёх пинах (CS 51, CLK 48, DI 55, DO 49). Игра записывается на неё с SD-карты прямо из меню, запускается с неё и хранит на ней сохранения.
- **Меню на маленьком экране** в том же стиле: цвета, иконки, скруглённая полоса выбора, заголовок и строка значения.
- **SPI-дисплей ST7735S 128×128:** работает одновременно с HDMI, около 60 кадров/с. *Fit* — весь экран со сглаживанием (128×115), *Crop* — центр 1:1. Меню тоже выводится на дисплей.
- **Управление:**
  - DualShock 2 через адаптер Sipeed;
  - 8 обычных кнопок на пинах;
  - пульт с ПК через USB-UART платы.

  Всё работает одновременно.
- **Debug-режим:** FPS, режим GB/GBC, скорость CPU, нажатые кнопки, время работы, имя игры, маппер и размер ROM. Выводится в чёрные поля HDMI и в верхнюю строку LCD.
- **Процессор меню:** FemtoRV32 (RV32E), прошивка в SDRAM, FatFs для карты.

## Быстрый старт

```sh
./build.sh gbc_top                                  # yosys -> nextpnr -> gowin_pack (~10 минут)
fw/build.sh                                         # прошивка меню (RISC-V GCC)
./flash.sh all                                      # бит-поток и прошивка меню во flash
python tools/make_games.py build/games.bin games/ucity.gbc=uCity games/libbet.gb
./flash.sh games                                    # встроенные игры во flash с адреса 0x200000
```

Для SD-карты: скопировать `.gb` / `.gbc` (в любые папки) на microSD с FAT32 или exFAT и вставить в слот платы.

Подробности про тулчейн, драйвер (Zadig, WinUSB на «20K's FRIEND (Interface 0)») и опции сборки — в [build.md](build.md).

## Подключение

Кнопки замыкают пин на GND, подтяжка включена внутри FPGA. Дисплей питается от 3.3 В.

| Сигнал | Пин | | Сигнал | Пин |
|---|---|---|---|---|
| Вверх | 25 | | LCD SCL | 73 |
| Вниз | 26 | | LCD SDA | 74 |
| Влево | 27 | | LCD RES | 71 |
| Вправо | 28 | | LCD DC | 72 |
| A | 29 | | LCD CS | 53 |
| B | 30 | | LCD BL | 52 |
| Select | 31 | | DualShock 2 | 17–20 (адаптер Sipeed) |
| Start | 77 | | Пищалка + / − | 76 / 75 |
| microSD | слот на плате | | HDMI | на плате |

**Если картинка на LCD сдвинута, отзеркалена или перепутаны красный и синий:** поправить параметры `MADCTL`, `X_OFS`, `Y_OFS`, `INVERT` у `lcd_st7735`. Подробности — в [hardware.md](hardware.md).

## Ограничения

- **Проверено на плате:** новое меню, загрузка и переключение игр из flash, сохранения во flash (восстанавливаются после перезагрузки), настройки, выключение и включение HDMI, сон и пробуждение.
- **На железе пока не проверены:** загрузка и сохранения на SD-карте (карты в слоте при проверке не было), пищалка, дисплей (только симуляция), DualShock 2 и кнопки.
- **Нет часов реального времени** для MBC3 и сохранений состояния; EEPROM MBC7 не сохраняется.
- **Потребление не измерялось:** энергосбережение реализовано, но токи я не мерил.
- **Редкие мапперы отключены, чтобы хватило места:** MBC6, MBC7, MMM01, камера, TAMA5, Rocket, Sachen, MegaDuck. Включаются ключом `DEFS="-D ALL_MAPPERS"`, но тогда ядро может не влезть.
