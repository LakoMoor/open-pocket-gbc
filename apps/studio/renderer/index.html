Open Pocket GBC

USB cable to the Tang Nano 20K. If writing stops with "bulk write failed", replug the cable and try again: a failed write can always be repeated, the board is never bricked.

SD card

Puts opgbc_fw.bin and opgbc_fpga.bin on the card. On the board: Menu › System › System Update.

  1. Pick the card above; the files go to its root.
  2. Put the card in the board and open the menu.
  3. System › System Update › Install Firmware or Install Bitstream.
  4. Firmware restarts the menu; after the bitstream switch the power off and on.

Board settings

The settings of the board's menu, over USB (firmware 1.6 or newer). A change is applied and stored on the board at once.

Remote

Buttons over the USB serial port. Keyboard: arrows, X = A, Z = B, Enter = Start, Backspace = Select, M = menu.
